Abstract

네트워크 침입 탐지 시스템(NIDS)에서 공격 트래픽은 전체 데이터의 극히 일부를 차지하는 극심한 클래스 불균형 문제가 존재합니다. 본 연구는 이를 해결하기 위해 Autoencoder, CNN, LSTM을 병렬 판별기로 결합한 3D-GAN(Triple Discriminator GAN) 아키텍처를 제안합니다. Generator는 정상 분포를 학습하고, 세 판별기는 각각 재구성 오류, 공간적 패턴, 시간 의존성을 전문적으로 학습합니다. CIC-UNSW-NB15 데이터셋에서 기존 SMOTE 기반 방법 대비 우수한 성능을 보여줍니다.

🔄

Parallel Discrimination

세 판별기가 서로 다른 관점(재구성/공간/시간)으로 동시에 학습. 단일 판별기 대비 다양한 공격 패턴 포착.

⚖️

Imbalance Solution

GAN Generator가 소수 클래스(공격 트래픽) 합성 데이터를 생성. SMOTE 대비 현실적인 분포 학습.

🎯

Multi-class Detection

원본 공격 레이블을 Benign / 정보 수집 및 분석 / 시스템 침해 및 악성 행위 / 서비스 방해의 4개 클래스로 재구성해 실험. 클래스 불균형 환경에서 다중 탐지 성능을 검증합니다.

Quick Start

실행 방법

terminal 
# Clone repository
$ git clone https://github.com/tndn-kim/3DGAN

# Install dependencies
$ pip install -r requirements.txt

# Train 3D-GAN
$ python train.py --dataset UNSW-NB15 \
    --epochs 200 --batch_size 256

# Evaluate
$ python evaluate.py --checkpoint best.pt
